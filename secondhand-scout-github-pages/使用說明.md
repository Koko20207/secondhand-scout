# 搜貨衣櫃

這是一個給 iPhone 和電腦用的二手衣搜貨工具。它不是 Android APK；iPhone 用的是 Safari 打開，再加入主畫面。

## 目前功能

- 搜尋特定品牌二手衣
- 設定最高進貨價和預估售價
- 同時打開蝦皮、Yahoo、露天、旋轉拍賣、Google 搜尋
- 建立監控條件
- 收藏商品和記錄進貨價、預估售價
- 收貨評分，快速判斷值不值得收
- 利潤試算
- 一鍵產生議價訊息
- 匯出和匯入資料備份

## 怎麼打開

1. 在這個資料夾按右鍵 `start-secondhand-scout.ps1`
2. 選擇用 PowerShell 執行
3. 電腦會自動開啟 `http://127.0.0.1:4173/`

## iPhone 怎麼用

1. 電腦和 iPhone 連同一個 Wi-Fi
2. 執行 `start-secondhand-scout.ps1`
3. 看視窗裡的 iPhone 網址，例如 `http://192.168.x.x:4173/`
4. 在 iPhone Safari 打開
5. 按分享按鈕
6. 選 `加入主畫面`

## 重要限制

蝦皮、Yahoo、旋轉拍賣等平台通常不讓外部 App 直接自動抓完整商品資料，所以這版採用穩定做法：幫你建立搜尋條件、快速打開各平台、記錄收藏和利潤。真正每天自動抓價格並推播，需要再做一個雲端後台，而且通常要避開平台規則風險。
